页面纵向顺序（三套一致）

  • ① 标题 Snake（占原 Core X 位置）
  • ② 设备信息：机型 / 内核 / 管理器（点击切换）
  • ③ 进度：当前环节 + 百分比 + 滚动环节 + 耗时
  • ④ 输出：命令原始字符，自动贴底滚动
  • ⑤ 底部固定三按钮：命令 / 扩展 / 授权·越狱

状态与文案

  • 未授权：管理器「—」，输出区空提示，主按钮＝一键授权
  • 已授权：管理器显示实际名称，主按钮＝一键越狱
  • 运行中：主按钮＝中止，右上计时开始走
  • 完成：计时定格为「总耗时 00:42」，进度 100%
  • 已删除：SELinux / tracefs / 关于 / 历史 / 日志 Tab

需要你定

  • 选 A / B / C（可混搭：A 的结构 + C 的无卡片）

  • 管理器点击：底部弹选择列表，还是直接轮换
  • 扩展：底部弹层，还是独立页面
